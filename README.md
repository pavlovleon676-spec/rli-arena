# RLI Arena (Физмат-арена Республиканского лицея-интерната)

Инновационная образовательная мультиплеерная веб-платформа для Республиканского лицея-интерната (РЛИ), объединяющая геймификацию физмат-образования (ЕГЭ и Олимпиады), цифровую трансформацию (Paperless), взаимопомощь лицеистов (SOS-менторство) и смарт-оцифровку конспектов с помощью искусственного интеллекта.

---

## 🎯 Ключевые возможности

1. **Реальный мультиплеер и PVP-дуэли:**
   - Шахматный рейтинг **ELO (500 стартовый)**.
   - Синхронные поединки в реальном времени между ПК и смартфонами по локальной сети / Wi-Fi.
   - Античит-система (контроль минимального времени реакции < 1.5 сек).
   - Задачи по трем направлениям: Физика, Профильная математика, Информатика (уровни: ЕГЭ и Олимпиада).

2. **Битва 5 профилей РЛИ:**
   - Соревнование между классами лицея: **Физмат**, **Политех**, **Роснефть**, **Гум**, **ГК**.
   - Командный рейтинг формируется победами каждого ученика.

3. **SOS-Менторство (Взаимопомощь лицеистов):**
   - Ученик оставляет запрос с номером кабинета (например, «305 каб.») и темой задачи.
   - Одноклассники или старшеклассники отправляют подробное решение с формулами и получают **+30 ELO**.

4. **ИИ-Оцифровщик конспектов (Paperless):**
   - Ученик вставляет рукописный текст или конспект урока.
   - Алгоритм извлекает ключевые формулы (Ньютон, импульс, кинематика, закон Ома, теорема Виета, O-нотация).
   - Автоматически генерирует тезисы и проверочный квиз для закрепления материала.

5. **Игровой уровень и прогресс:**
   - Динамические ранги: от *Новичка РЛИ* до *Грандмастера*.
   - Шкала опыта и стрик побед.

## 🚀 Быстрый запуск

### Способ 1: Автономный запуск в 1 клик на Windows (без установки)
Просто дважды кликните по файлу:
```
ЗАПУСК_РЛИ_АРЕНА.bat
```
Сайт автоматически откроется в браузере по адресу:
```
http://localhost:5173/
```

### Способ 2: Запуск через терминал
```bash
# 1. Установка зависимостей (если запускается на новом компьютере)
npm install

# 2. Сборка продакшн-бандла
npm run build

# 3. Запуск локального сервера
npm run preview
```

## 🛠️ Стек технологий
* **Frontend:** React 18, Vite 6, Tailwind CSS, Lucide Icons, KaTeX-совместимый движок формул.
* **Backend:** Node.js API Middleware, JSON-база данных (`rli_data.json`) с мгновенной синхронизацией по WebSocket/Broadcast/Polling.
* **AI Engine:** Процедурный генератор задач + Google Gemini API (опционально).
* **Сеть:** Zero-lag Local Network Sync (работает 100% оффлайн в школьном Wi-Fi).
