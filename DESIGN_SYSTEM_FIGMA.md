# Дизайн-система и UI Kit: RLI Arena (Figma Design System)

Документация и спецификация пользовательского интерфейса мобильной веб-платформы **RLI Arena** для защиты перед жюри и менторами хакатона.

---

## 🎨 1. Концепция и философия интерфейса
Дизайн разработан на стыке трёх передовых продуктовых дизайн-парадигм:
1. **Apple Human Interface Guidelines (HIG):**
   * Скругления карточек $R = 20\text{px}$ (Squircle).
   * Микро-тени с мягким рассеиванием (`box-shadow: 0 8px 24px rgba(0,0,0,0.06)`).
   * Тактильный отклик при нажатии (`active:scale-98`).
2. **Duolingo Gamification (Физмат-геймификация):**
   * Живые индикаторы ELO-рейтинга и серии побед (Flame / Streak).
   * Прогресс-бар с плавным кубическим заполнением (`cubic-bezier(0.22, 1, 0.36, 1)`).
   * Цветовая дифференциация 5 лицейских профилей (Физмат, Политех, Роснефть, Гум, ГК).
3. **Notion Paperless Clean (Академическая ясность):**
   * Теплый песочный фон (`#F5F2EB`) в светлой теме для снижения усталости глаз при чтении.
   * Моноширинный шрифт **JetBrains Mono** для физических формул и программного кода.
   * Контрастная графитовая тёмная тема (`#18181B` / `#1C1C20`) для вечерних занятий.

## 📐 2. Дизайн-токены (Design Tokens)

### Цветовая палитра:
| Токен | Значение (HEX) | Назначение |
| :--- | :--- | :--- |
| `--color-terra` | `#EA580C` | Главный фирменный акцент (кнопки вызова, победа) |
| `--color-emerald` | `#064E3B` | Академический градиент и успешные ответы |
| `--color-amber` | `#F59E0B` | Золотой ELO-рейтинг, модерация Совета Лицея |
| `--color-sand` (Light) | `#F5F2EB` | Песочный бумажный фон (Paperless) |
| `--color-graphite` (Dark) | `#18181B` | Глубокий графитовый фон OLED |
| `--color-card-dark` | `#1C1C20` | Поверхность карточек в тёмной теме |

### Типографика:
* **Основной шрифт:** `Plus Jakarta Sans`, `Inter`, sans-serif (геометрический гротеск с открытыми апертурами).
* **Формулы и код:** `JetBrains Mono`, monospace.
* **Иерархия:**
  * Заголовок H1: `20px / 28px` (Bold 800)
  * Заголовок H2: `16px / 24px` (Bold 700)
  * Основной текст: `14px / 20px` (Medium 500)
  * Бейджи и теги: `10px / 12px` (Bold 700, Uppercase tracking +0.5px)

## 📱 3. Структура экранов (Mobile-First 390 × 844)

1. **Главная (Home & Class Leaderboard):**
   * Карточка лицеиста: ELO, статус (В сети), прогресс-бар уровня, количество сохраненных тетрадных листов (Paperless).
   * Битва 5 лицейских классов: рейтинг профилей РЛИ в реальном времени.
   * Топ лицеистов: живая таблица лидеров с аватарками и ELO.
2. **Арена Дуэлей (PvP Arena):**
   * Быстрый старт соло-тренировки (ФИПИ или Олимпиада).
   * Список соперников онлайн с кнопкой вызова в 1 клик (`⚡ Вызвать`).
   * Экран боя: 30-секундный таймер, античит-контроль реакции, одновременный выбор вариантов ответа.
3. **Конспекты РЛИ (Smart OCR & Gemini AI):**
   * Галерея оцифрованных рукописей с фото тетради.
   * Смарт-структурирование: тема, формулы, тезисы и мини-квиз для закрепления (+15 XP).
4. **SOS-Менторство (Peer-to-Peer Help):**
   * Запросы помощи по кабинетам лицея (например, «305 каб.»).
   * Открытый тред ответов с формулами (+30 ELO за принятое решение).
   * Панель модерации для Совета Лицея (жалобы и удаление токсичных ответов).
5. **Система и настройки (Settings):**
   * Монитор статуса серверного ИИ Gemini 2.0 Flash.
   * Кнопка теста задержки API (Ping).
   * Системный лог событий в реальном времени.

## ⚡ 4. Как дизайнеру открыть готовый проект в Figma за 1 минуту!

Для того чтобы получить **100% редактируемый файл Figma с автолейаутами, слоями и векторными иконками**:

1. Откройте **[Figma](https://figma.com)** и создайте новый пустой файл: `RLI Arena — Mobile UI Kit`.
2. В верхнем меню нажмите **Plugins** $\rightarrow$ найдите плагин **`html.to.design`** (самый популярный бесплатный плагин импорта).
3. Вставьте ссылку на наш продакшн-сайт:
   ```
   https://rli-arena.onrender.com/
   ```
4. Выберите параметры:
   * **Device:** `Mobile (iPhone 14 / 390px)`
   * Нажмите **Import**.
5. Плагин за 10 секунд создаст векторный артборд со всеми кнопками, бейджами и карточками!
6. Повторите для вкладок **«Дуэль»**, **«Конспекты»** и переключенной **«Тёмной темы»**.
7. В итоге у вас будет роскошная презентационная доска Figma с 10 готовыми артбордами, которую можно уверенно показывать жюри!
